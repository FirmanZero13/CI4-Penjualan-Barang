# Sistem CRUD Penjualan Barang
Project ini adalah aplikasi web sederhana untuk mengelola data barang (Create, Read, Update, Delete).

## Teknologi yang Digunakan
* Framework: CodeIgniter 4
* UI/CSS: Bootstrap 5
* Database: MySQL

## Fitur Aplikasi
* Menambah data barang (Nama, Harga, Stok).
* Menampilkan daftar barang dalam bentuk tabel.
* Mengedit data barang.
* Menghapus data barang.
